# Interview Scheduling Platform

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Spring Boot Framework
- Database: MongoDB

## Features
- Cordinator/Interviwer - Registration/Login
- Company Dashboard
- Job Role Management
- Candidate Management
- Feedback Loop
- Candiadte Pipleine
- REST APIs

## Run Backend
```bash
cd backend
mvn spring-boot:run
```

## Run Frontend
Open index.html using Live Server in VS Code.

## MongoDB
Ensure MongoDB is running locally:
mongodb://localhost:27017/interview_platform
